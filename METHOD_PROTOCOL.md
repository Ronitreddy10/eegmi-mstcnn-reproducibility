# Analysis protocol to cite in the revised manuscript

The corrected analysis uses nested subject-grouped evaluation. The outer loop is a ten-fold `GroupKFold` in which subject identifiers, rather than trials, define groups. Within each outer training partition, a grouped inner hold-out set is used solely to select the checkpoint according to macro-F1. The selected checkpoint is then evaluated once on untouched outer-test subjects, which are never used for epoch selection, early stopping, or checkpoint selection. The 83,080,458-parameter reference configuration is repeated with random seeds 42, 123, and 2026 under both unweighted and effective-number cross-entropy. Capacity variants and neural baselines are compared at seed 42; the 19,936,294-parameter result is therefore a seed-42 capacity finding rather than a three-seed robustness result.

Capacity is examined using four otherwise corresponding MST-CNN variants containing 551,144, 4,956,614, 19,936,294, and 83,080,458 trainable parameters. Effective-number-weighted cross-entropy is compared with unweighted cross-entropy to test training-time class-imbalance correction. Accuracy is secondary; balanced accuracy, macro-F1, and per-class recall are the primary class-sensitive outcomes. EEGNet, ShallowConvNet, a DeepConvNet-style temporal CNN, and a residual 1D CNN provide compact and mid-sized neural comparisons. Trainable parameters, MACs, FLOPs defined as twice the MAC count, and batch-1 inference latency on the reported Kaggle device are recorded for every model.

This text describes the implemented rerun protocol. The checked numerical summaries in `analysis_outputs/` were generated from the completed 13-experiment archive containing 130 outer-fold result files.
