# Reviewer experiment protocol

The corrected analysis uses nested subject-grouped evaluation. The outer loop is a ten-fold `GroupKFold` in which subject identifiers, rather than trials, define groups. Within each outer training partition, a grouped inner hold-out set is used solely to select the checkpoint according to macro-F1. The selected checkpoint is then evaluated once on untouched outer-test subjects, which are never used for epoch selection, early stopping, or checkpoint selection. The 83,080,458-parameter reference configuration is repeated with random seeds 42, 123, and 2026 under both unweighted and effective-number cross-entropy. Capacity variants and neural baselines are compared at seed 42; the 19,936,294-parameter result is therefore a seed-42 capacity finding rather than a three-seed robustness result.

The reference input window is 0--4 s at the native 160 Hz sampling rate. MNE includes both endpoints, so the reference input tensor contains 641 samples per channel. Temporal robustness changes only the cue-relative bounds: 0--2 s (321 samples), 0--3 s (481), 0--4 s (641), and 1--4 s (481). Dataset mapping, preprocessing, outer folds, inner selection, optimizer, and training limits remain fixed.

Capacity is examined using four compound width/pooling variants of the same four-stream MST-CNN design, containing 551,144, 4,956,614, 19,936,294, and 83,080,458 trainable parameters. The new temporal-scale ablation uses the 19.94M width settings and evaluates streams with kernels 7, 9, 11, 13, 7+9, 7+9+11, and 7+9+11+13. Because removing streams also removes parameters, this is explicitly reported as a scale-count ablation rather than a parameter-matched causal comparison. Exact parameters, MACs, FLOPs defined as twice the MAC count, and batch-1 computational inference latency are measured for every configuration.

Accuracy is secondary; balanced accuracy, macro-F1, and per-class recall are the primary class-sensitive outcomes. EEGNet, ShallowConvNet, a DeepConvNet-style temporal CNN, and a residual 1D CNN retain the manuscript's effective-number CE setting. CSP+LDA adds a classical comparison using the same subject-wise outer folds and preprocessing. CSP uses eight components and is fitted only on each outer-training partition.

Every outer-test trial is saved with its subject ID, true label, predicted label, and original dataset index. Subject-level distributions report mean, sample SD, median, IQR, minimum, and maximum. Confidence intervals use 10,000 percentile bootstrap resamples of whole subject prediction blocks with seed 42. Paired model comparisons align subjects and report mean difference, median difference, a subject-bootstrap 95% CI, paired rank-biserial correlation, raw two-sided Wilcoxon p, and Holm-adjusted p. Fold summaries are descriptive because training partitions overlap.

The classifier filter is an explicitly logged MNE `Raw.filter` 4--40 Hz zero-phase Hamming-window FIR designed with `firwin`, automatic length and transition bandwidths, and `reflect_limited` edge padding. It is applied to continuous runs before epoch extraction; per-channel epoch z-scoring follows. The realized tap count and order are recorded at runtime with the MNE version.

The physiology branch audits all classification-eligible subjects under the 300 µV peak-to-peak rejection rule. It records annotation, epochable, rejected, and retained trial counts per class; subject exclusion reasons; class-specific exclusion triggers; and equality of retained class counts. The updated physiology cohort contains 85 subjects with at least one retained trial in every class. The remaining 18 subjects lose all retained trials from at least one class under the 300 µV rule and are excluded from the physiology analysis.

This text describes the implemented reviewer rerun protocol. Numerical claims must be taken only from completed Kaggle outputs, not from synthetic smoke tests.
